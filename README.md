# Photo PDF Maker

画像を補正し、並べ替えてPDFにまとめる、依存関係なしの小さなブラウザアプリです。

公開URL: https://meta1529-dev.github.io/photo-pdf-maker/

教科書や書類をスマホアプリでスキャンしてJPG/PNGとして書き出したあと、別アプリで結合してPDF化する手間を減らすために作りました。

## できること

- 複数画像の追加
- `画像を追加` から `スキャンする` を選んで撮影画像を取り込む
- 青い枠でスキャン範囲を選択
- 紙の自動検出と台形補正
- 文字を読みやすくする補正
- ページ端の指や影っぽい写り込みの簡易軽減
- 追加した画像を一覧で確認
- ドラッグやボタンでの並べ替え
- 画像ごとの左右回転
- A4縦/A4横/A4自動/写真比率の切り替え
- 余白、配置、画質、解像度の調整
- PDFファイルの作成

## 使い方

`index.html` をブラウザで開きます。

1. `画像を追加` から画像を選ぶ
2. 撮影から始める場合は `スキャンする` を選ぶ
3. 必要なら青い枠、順番、回転を調整する
4. ファイル名やページ設定を整える
5. `PDFを作成` を押す

画像はサーバーに送信されず、ブラウザ内でPDF化されます。

## ファイル構成

- `index.html`: 画面
- `styles.css`: 見た目
- `app.js`: 画像処理とPDF生成

## 今回の更新

- iPhone・iPadの写真ピッカーが返す順番をアプリ内で勝手に変更せず、画面の番号順をそのままPDFのページ順にします。
- 「ファイル名順（自然）」「追加した順」「撮影日時順」「順番を反転」を選べます。
- PDF作成後は、対応端末では共有シートから「ファイルに保存」を選べます。対応していないブラウザでは従来どおりダウンロードに切り替わります。
- 画像の追加、並べ替え、PDF作成はこれまでどおり端末内で処理します。
